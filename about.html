关于本项目

一个「天气查询 + 待办清单」的前端作业项目：原生 HTML / CSS / JavaScript（ES Modules），零第三方依赖、零构建步骤，双击或起一个静态服务器即可运行。

✨ 功能清单

  • 天气：城市搜索（地理编码）、当前温度 / 天气 / 风速 / 湿度 / 体感 / 降水、未来 3 天预报、°C ↔ °F 切换。
  • 天气：搜索历史（去重，最多 8 条）、收藏城市、依据天气与昼夜自动切换背景。
  • 待办：添加、删除、编辑、完成、三级优先级、按状态 / 优先级筛选、关键词搜索、排序、清空已完成。
  • 待办：完成率进度条与统计卡，数据持久化到 localStorage。
  • 统计：完成率环形图、优先级分布条形图、近 7 天完成趋势柱状图、天气查询次数与热门城市。
  • UI：简洁现代卡片风格、响应式（手机 / 平板 / 桌面）、深色模式（跟随系统 + 手动切换并记忆）。
  • 健壮性：接口超时与失败有友好提示；地理编码失败自动降级到内置城市表；完全离线可用「演示数据」查看页面效果。

🧱 技术栈

  • HTML5 语义化标签 + 无障碍属性（aria-*、role、跳转焦点样式）。
  • CSS3：自定义属性（CSS 变量）实现主题、Flex / Grid 布局、backdrop-filter、color-mix()、动画与过渡、prefers-color-scheme、prefers-reduced-motion、打印样式。
  • JavaScript（ES2015+）：ES Modules 分文件、fetch + AbortController、可选链、异步 / 错误分类处理。
  • 数据持久化：localStorage（隐私模式下自动降级为内存存储，不报错）。
  • 安全：渲染用户输入一律使用 textContent / DOM API，从根本上避免 XSS。

🔌 使用的接口

全部来自 Open-Meteo，免费、无需 API Key、支持 HTTPS 与跨域：

  • 地理编码：https://geocoding-api.open-meteo.com/v1/search?name=杭州&count=6&language=zh&format=json
  • 天气预报：https://api.open-meteo.com/v1/forecast?latitude=..&longitude=..&current=..&daily=..&timezone=auto
// js/api.js 中实际请求的字段
current = temperature_2m, relative_humidity_2m, apparent_temperature,
          is_day, precipitation, weather_code, wind_speed_10m, wind_direction_10m
daily   = weather_code, temperature_2m_max, temperature_2m_min,
          precipitation_probability_max, sunrise, sunset
forecast_days = 4   // 第 1 天为今天，页面展示后 3 天

🚀 运行步骤

因为使用了 ES Modules，请通过 HTTP 打开页面（直接双击 file:// 会被浏览器的模块跨域策略拦截）：

# 方式一：运行项目自带的 server.py（推荐，Python 标准库零依赖）
cd p1_todo
python server.py            # 自动选端口并打开 http://127.0.0.1:8808
python server.py 9000       # 指定端口
python server.py --host 0.0.0.0   # 手机连同一 WiFi 预览响应式
#（macOS / Linux 用 python3 server.py）

# 方式二：Python 标准库一行命令
python -m http.server 8808

# 方式三：Node.js
npx serve . -l 8808

# 方式四：VS Code 安装 Live Server 插件，右键 index.html → Open with Live Server

❓ 常见问题

  • 查不到天气 / 一直转圈？请检查网络是否能访问 api.open-meteo.com；若被网络策略拦截，可点击首页的「演示数据」按钮查看完整界面效果（页面会明确标注为演示数据）。
  • 数据存在哪里？只存在你自己浏览器的 localStorage，键名统一以 wtapp: 开头，不会上传服务器。
  • 怎么切换深色模式？点右上角图标，或按 Shift + D，选择会被记住；未手动选择时自动跟随系统。
